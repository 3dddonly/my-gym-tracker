MY GYM TRACKER — mobilna web aplikacija

Sadrži:
- Upper A, Lower A, Upper B, Lower B treninge
- unos težine i ponavljanja za svaku seriju
- čekiranje završenih serija
- istoriju treninga i najbolje zabeležene težine
- grafikon napretka po vežbi
- praćenje telesne težine
- čuvanje podataka lokalno na uređaju (localStorage)
- izvoz rezervne kopije podataka u JSON formatu

Kako da je koristiš:
1. Raspakuj ZIP.
2. Za testiranje otvori index.html u browseru.
3. Za instalaciju kao pravu ikonicu na početnom ekranu telefona, fajlove postavi na HTTPS hosting (npr. GitHub Pages).
4. Otvori objavljeni HTTPS link na telefonu:
   - Android/Chrome: meni ⋮ → Install app / Add to Home screen
   - iPhone/Safari: Share → Add to Home Screen

Napomena:
- Podaci se čuvaju u browseru na tom uređaju. Nemoj brisati podatke browsera bez prethodnog izvoza backup-a.
- Aplikacija ne sinhronizuje automatski podatke između različitih uređaja.
- U Lower B je Kickback machine postavljen na 3×12 kao početna vrednost; možeš prilagoditi plan kasnije.
